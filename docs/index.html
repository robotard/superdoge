Super Doge · Owner runbook

Bot, community
& airdrop setup

The GitHub repo contains the bot backend. Cloudflare Workers runs it. Telegram hosts the Super Doge Community at t.me/superdogecommunity, linked to @SuperDogeAgent. This guide walks through setup and day-to-day admin steps.

Backend: GitHub → Cloudflare Worker Chat: Telegram Airdrop list: D1 + CSV
Keep the bot token private.

Human admins do not need the bot token. Add their Telegram numeric IDs to Cloudflare instead. Store the token only as the encrypted Worker secret TELEGRAM_BOT_TOKEN; never commit it to GitHub or paste it into this guide.

One-time setup

  1. Get the bot token. In Telegram, open @BotFather. Use /mybots, select @SuperDogeAgent, then open API Token. If the bot has not been created, create it with /newbot. Keep the token private.
  2. Create the Telegram group. Open the Super Doge Community group. If you administer it, add @SuperDogeAgent and add the human admins you trust in the group’s Administrators settings.
  3. Give the bot the needed group permission. Make @SuperDogeAgent a group admin with Delete messages permission. It needs to receive group messages to find spam and remove it. It does not mute or ban members, so do not grant ban/restrict permissions. Pin the bot link and moderation rules in the group.
  4. Set the bot’s menu. In BotFather use /setjoingroups to allow groups, then /setcommands and paste this public command list:
    start - Welcome and Super Doge links
info - Super Doge project information
airdrop - Register a wallet privately
cancel - Cancel wallet registration
    Keep /export off the public menu. Admins type it privately when registration should close.
  5. Set up the D1 database. Create a Cloudflare D1 database named superdoge-airdrop. Put its ID into bot/wrangler.jsonc, replacing REPLACE_WITH_D1_DATABASE_ID, and save the change to GitHub.
  6. Connect the backend to Cloudflare. In Workers & Pages, create/connect the Worker from this GitHub repo. Set its root folder to bot and Worker name to superdoge-airdrop-bot. The Wrangler config binds D1 as DB and sets an hourly cleanup schedule.
  7. Add Cloudflare settings. Set the Worker variables and encrypted secrets listed below. Dates must be real UTC dates, not the examples. Set the IDs for every person who needs the export command.
  8. Apply the database migrations and deploy. From Terminal in the repo folder, run the copyable commands below. Complete Cloudflare sign-in if asked.
  9. Connect Telegram to the Worker. Set the Telegram webhook using the Worker URL and webhook secret, using the copyable command below.
  10. Test before inviting members. Test `/start`, `/info`, and `/airdrop` in private chat; then test a new-member welcome, link filtering, flood filtering, and admin exports in the group. Use a throwaway wallet address.

Cloudflare variables and secrets

Ordinary variables

  • BOT_USERNAME: SuperDogeAgent without @
  • ADMIN_TELEGRAM_IDS: numeric IDs of all people allowed to close intake and export CSV, comma-separated (example format: 123456789,234567890)
  • MODERATOR_IDS: optional comma-separated IDs that bypass spam moderation but cannot export
  • AIRDROP_CLOSES_AT: UTC ISO date/time, e.g. 2026-12-31T23:59:00Z
  • AIRDROP_DELETE_AFTER: later UTC ISO date/time

Encrypted secrets

  • TELEGRAM_BOT_TOKEN: token from BotFather
  • TELEGRAM_WEBHOOK_SECRET: create a random value with openssl rand -hex 32

Enter these in Cloudflare’s secret fields. Never put them in GitHub or the HTML file.

Find each admin ID: each human admin can ask @userinfobot for their numeric Telegram ID. Put all IDs in ADMIN_TELEGRAM_IDS, separated by commas and with no spaces if convenient. They do not share or need the bot token.

Terminal commands

Use the repository on your Mac. If you already cloned it, open Terminal in that folder and run git pull first. Otherwise clone it, then run the rest:

git clone https://github.com/robotard/superdoge.git
cd superdoge
npx wrangler login
npx wrangler d1 migrations apply superdoge-airdrop --remote --config bot/wrangler.jsonc
npx wrangler deploy --config bot/wrangler.jsonc

For an existing local clone, skip the first two lines and run git pull before the Wrangler commands.

When deployed, the Worker health address is https://YOUR-WORKER.workers.dev/health. It should respond: “Super Doge bot is ready.”

Set Telegram’s webhook

Replace YOUR-WORKER.workers.dev with the Worker address shown in Cloudflare. Use the exact webhook secret saved in Cloudflare. The token and secret are typed without echoing in Terminal:

read -s "TG_TOKEN?BotFather token: "; echo
read -s "HOOK_SECRET?Webhook secret: "; echo
curl -sS -X POST "https://api.telegram.org/bot${TG_TOKEN}/setWebhook" \\
  --data-urlencode "url=https://YOUR-WORKER.workers.dev/telegram" \\
  --data-urlencode "secret_token=${HOOK_SECRET}"
unset TG_TOKEN HOOK_SECRET

How several admins work

  1. Add each person as a human group admin in Telegram’s group settings. Choose their group permissions there.
  2. Add each person’s numeric ID to Cloudflare’s ADMIN_TELEGRAM_IDS. These people can use the private /export command and are exempt from spam filters.
  3. Each admin must open a private chat with @SuperDogeAgent and press Start once. Telegram won’t let the bot initiate a private chat with someone who has never started it.
  4. Any listed admin can privately send /export. This immediately closes registration and sends the CSV to that admin’s private chat. The bot token remains with the account owner and is not shared with admins.

What the bot does in the group

  • Welcomes new members and points them to Super Doge information and @SuperDogeAgent.
  • For the first 24 hours after joining, removes links except superdoge.co and t.me/SuperDogeAgent.
  • Removes messages after a person sends more than 8 messages in 10 seconds. It warns on the first flood event.
  • Does not mute, ban, or otherwise restrict people.

Pin these rules so community members know what the bot will remove. For access, the bot needs group-admin permission to delete messages. Human admins listed in the configuration are exempt; other moderators can be added to MODERATOR_IDS.

Airdrop steps and data handling

  1. Set final eligibility rules and dates before opening registrations.
  2. Members privately send /airdrop to @SuperDogeAgent, then submit a public Solana wallet address. The bot rejects invalid-format and duplicate entries. It does not verify ownership or eligibility.
  3. Any configured admin sends /export privately to close registration and receive a CSV with one unique wallet per row.
  4. The Worker deletes active D1 entries at the configured deletion date. The admin must also delete the CSV from Telegram and all downloaded copies after distribution. Check Cloudflare’s database backup retention separately before promising complete erasure.
