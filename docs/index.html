Get the bot online

The GitHub repo holds the bot backend code. Cloudflare runs that backend. Telegram hosts the Super Doge Community group, linked to @SuperDogeAgent. Follow this checklist to connect them; the bot is not live until the Cloudflare and Telegram steps are done.

GitHub: robotard/superdoge Website: superdoge.co
First: review the prepared files.

They are in the draft PR. Merge it when you’re happy with them: open the setup PR. It adds files without replacing the current homepage.

Our actions, in order

  1. Merge the PR. Cloudflare Pages should publish the new /docs/ page through its existing GitHub connection. The current homepage remains as it is.
  2. Get the @SuperDogeAgent bot token. If @SuperDogeAgent already exists, use that bot and its token. If it still needs creating, create it with @BotFather. Save the token privately. Never put the token in GitHub.
  3. Create or open the Telegram group “Super Doge Community.” Add @SuperDogeAgent to the group as an admin with the Delete messages permission. It needs to see group messages to moderate spam. Do not grant ban or restrict permissions; the bot only removes messages. In BotFather, use /setjoingroups to allow group use and /setcommands to add the commands below. Pin the bot link and a notice about the moderation rules in the group.
  4. Create the wallet database. In Cloudflare, create a D1 database named superdoge-airdrop. Copy its database ID into bot/wrangler.jsonc, replacing REPLACE_WITH_D1_DATABASE_ID, then save that edit to GitHub.
  5. Connect the bot files to Cloudflare Workers. Create a Worker from the GitHub repo. Set its root folder to bot and name it superdoge-airdrop-bot. The Wrangler file already connects the D1 database as DB and sets the hourly cleanup schedule.
  6. Add the bot settings in Cloudflare. In the Worker’s Settings, add the four ordinary variables below and the two encrypted secrets. Use your Telegram numeric ID (get it from @userinfobot). Pick the real registration and deletion dates in UTC.
  7. Create the database tables and deploy. On a Mac with Node.js, open Terminal in the repo folder and run the commands below. Approve Cloudflare sign-in when prompted.
  8. Connect Telegram to the Worker. Run the webhook command below using the Worker URL shown in Cloudflare and the same webhook secret saved in its settings.
  9. Test privately, then invite the community. Confirm that new members get a welcome; an external link from a new member is removed for the first 24 hours; and a burst over 8 messages in 10 seconds is removed. Then try /start, /info, and /airdrop. Use a throwaway wallet for the test. Confirm that /export sends the CSV to your admin Telegram account before sharing the group invite publicly.

BotFather command list

start - Welcome and Super Doge links
info - Super Doge project information
airdrop - Register a wallet privately
cancel - Cancel wallet registration

Do not add /export to the public menu. The admin types it privately when signups should close.

Cloudflare settings

Ordinary variables

  • BOT_USERNAME — SuperDogeAgent (without the @)
  • ADMIN_TELEGRAM_ID — your numeric Telegram user ID
  • AIRDROP_CLOSES_AT — UTC date/time, such as 2026-12-31T23:59:00Z
  • AIRDROP_DELETE_AFTER — later UTC date/time, such as 2027-01-31T23:59:00Z

Encrypted secrets

  • TELEGRAM_BOT_TOKEN — token from BotFather
  • TELEGRAM_WEBHOOK_SECRET — make one with openssl rand -hex 32

Put secrets in Cloudflare’s secret fields only. Do not add them to the repo or this page.

Terminal commands

If you already have the repo on your Mac, open Terminal in its folder. Otherwise, clone it first. Then sign in, create the tables, and deploy:

git clone https://github.com/robotard/superdoge.git
cd superdoge
npx wrangler login
npx wrangler d1 migrations apply superdoge-airdrop --remote --config bot/wrangler.jsonc
npx wrangler deploy --config bot/wrangler.jsonc

After deployment, the Worker address should have a health page at https://YOUR-WORKER.workers.dev/health. It should say “Super Doge bot is ready.”

Telegram webhook command

Replace YOUR-WORKER.workers.dev with the address shown on the Worker page. Paste this in Terminal. It asks for your token and webhook secret without showing them while you type.

read -s "TG_TOKEN?BotFather token: "; echo
read -s "HOOK_SECRET?Webhook secret: "; echo
curl -sS -X POST "https://api.telegram.org/bot${TG_TOKEN}/setWebhook" \\
  --data-urlencode "url=https://YOUR-WORKER.workers.dev/telegram" \\
  --data-urlencode "secret_token=${HOOK_SECRET}"
unset TG_TOKEN HOOK_SECRET

What the bot moderates

It welcomes new group members, removes external links from a member during their first 24 hours (official superdoge.co and t.me/SuperDogeAgent links are allowed), and removes messages after 8 messages in 10 seconds. It warns the group when it removes a message. It does not mute or ban members. Pin these rules in the group so members know what to expect.

What happens to the addresses?

Members use /airdrop in the bot’s private chat. The bot checks for duplicates and keeps addresses out of the group. When ready, the admin sends /export in a private chat; this closes signups and sends a CSV. The Worker deletes active D1 entries after the configured date. The admin must also delete the CSV from Telegram and any downloaded copies after distribution.
